# Память команды AIStack

Это обычная папка с Markdown-файлами на вашем компьютере. Её можно открыть в
Obsidian («Open folder as vault»), но сам Obsidian для работы не обязателен.

| Папка | Что там | Кто пишет |
|---|---|---|
| `profile/` | Профиль эксперта: ниша, аудитория, услуга, голос | Координатор (с ваших слов) |
| `facts/` | Проверяемые факты — с источником | Все агенты |
| `decisions/` | Решения, которые вы явно подтвердили | Только Координатор |
| `next-steps/` | Следующие шаги: один шаг — один файл | Координатор |

## Формат записи
```
---
type: fact | decision | next-step
date: YYYY-MM-DD
source: откуда это известно
status: проверено | гипотеза | открыт | закрыт | отменено
author: coordinator | designer | copywriter
---
Текст записи.
```

## Что здесь хранить нельзя
Ключи API, токены ботов, пароли, данные карт и чужие персональные данные.

Установщик создаёт только эти папки и файлы-подсказки и никогда не перезаписывает
ваши файлы при повторной установке.
