# TOOLS.md — Координатор-технарь

> Это заметки, а не переключатели: реальные возможности задаёт конфигурация OpenClaw.

## Что выбрано при установке
- **Модель по умолчанию:** `{{MODEL}}`
- **Vault (память команды):** `{{VAULT_PATH}}`
- **Боты:** по одному Telegram-боту на роль (Координатор, Дизайнер, Копирайтер).

## Диагностика (только чтение, ничего не меняет)
- `openclaw status` — общее состояние.
- `openclaw gateway status` — работает ли gateway.
- `openclaw models status` — какая модель выбрана и есть ли к ней доступ.
- `openclaw doctor` — поиск типичных проблем.

Менять модель, ключи и настройки ботов — только после «да» владельца.

## Что пока НЕ подключено установщиком
- Генерация картинок — Дизайнер готовит ТЗ; автоматическая генерация будет
  подключена отдельно после проверки доступа и сметы.
- Движок «Твоим голосом» — Копирайтер пишет по профилю из vault, пока движок
  не подключён и не проверен.
- Видео — отдельный маршрут, только со сметой и согласием владельца.
